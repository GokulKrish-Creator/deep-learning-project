# DeepVision AI
### Deep Learning for Steel Surface Defect Classification

DeepVision AI is a beginner-friendly computer vision project that uses a **Convolutional Neural Network (CNN)** to classify steel surface images into six defect categories. The model is trained in Google Colab, then used in a local Streamlit web app on Windows.

## What the project does

- Accepts a steel surface image from the user.
- Processes the image into the format expected by the trained CNN.
- Predicts one of six defect categories.
- Displays the predicted category and the model's top-three scores.
- Includes a warning when the highest score is low.

## Defect categories

The model is trained to classify images into these categories:

1. Crazing
2. Inclusion
3. Patches
4. Pitted surface
5. Rolled-in scale
6. Scratches

## Technology stack

- **Python** — programming language
- **TensorFlow / Keras** — deep learning model
- **CNN** — image classification architecture
- **Google Colab** — model training and evaluation
- **Streamlit** — interactive web interface
- **NumPy and Pillow** — image preprocessing
- **scikit-learn and Matplotlib** — evaluation and visualisation in the training notebook

## How it works

1. **Dataset:** The notebook loads labeled steel-surface images.
2. **Preprocessing:** Images are converted to grayscale, resized to 200 × 200 pixels, and pixel values are scaled to the 0–1 range inside the model.
3. **Training:** Convolution and pooling layers learn visual patterns from the training images.
4. **Evaluation:** The notebook reports test accuracy, precision, recall, F1-score, and a confusion matrix.
5. **Export:** The trained model and class-name list are saved from Google Colab.
6. **Prediction:** The Streamlit app loads those files and predicts the class for an uploaded image.

## Run the app on Windows

### First-time setup

Python 3.11 is recommended for the TensorFlow version used in this project.

1. Extract the project folder.
2. Train the model using `colab_training/DeepVision_AI_CNN_Training.ipynb` in Google Colab.
3. Download and extract `deepvision_export.zip`.
4. Copy these two files into `laptop_app/models/`:
   - `deepvision_cnn.keras`
   - `class_names.json`
5. Open PowerShell inside the `laptop_app` folder and run:

   ```powershell
   py -3.11 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install --upgrade pip
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

### Launch the app

After the first-time setup, simply **double-click `laptop_app/run_app.bat`**.

The app should open in your browser. If it does not, open:

`http://localhost:8501`

Keep the terminal window open while using the app. To stop the app, click the terminal window and press `Ctrl + C`.

## Limitations

- This is an **image classification** project: it predicts a category for the whole image. It does not draw boxes around defects or identify their exact location.
- The model may perform poorly on images that differ from the training dataset, including random images downloaded from the internet.
- The displayed score is the model's output score, not a guarantee that the prediction is correct.
- A predicted class should not be treated as a certified industrial quality decision. Real deployment requires testing on representative production data and human quality-control review.
